# Phish-Drift Detection

A calibrated, drift-aware evaluation framework for phishing URL detection.

## Research question
How do accuracy, calibration, and feature importance of phishing URL
classifiers degrade under temporal distribution shift, and which
lightweight adaptation strategies recover them?
